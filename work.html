Revved Up

Full-Stack Fitness Management System

Production platform serving 70+ participants with automated program management.

Live Demo GitHub

Click to read more

Revved Up is a full-stack fitness management platform I architected and implemented for Queen's Kinesiology's accessible fitness program. The system transitioned 70+ participants from manual paper-based program management to a fully automated digital workflow.

I designed a layered TypeScript/Node.js backend (controller, service, repository pattern) with role-based access control, enabling kinesiologists, trainers, students, and participants to have secure, role-specific access. The system automates program assignment, progress tracking, and personalized feedback generation.

For production deployment, I configured Azure infrastructure with reverse proxy (port routing), SSL encryption, and SQLite persistence. I also integrated email automation using Resend for session reminders and program notifications. The system is deployed to the official queensu.ca domain with comprehensive documentation for long-term maintenance by Queen's IT.

Spend Sight

iOS Finance App

Native iOS app with receipt scanning and spending visualizations.

Project Website GitHub

Click to read more

Spend Sight is a native iOS app that helps users track spending habits by automating receipt data extraction. Users can capture or upload a receipt photo, and the app automatically extracts details like store name, total amount, and date using Apple Vision Framework's OCR.

The app features a multi-view architecture including a scanner, receipt list, detail view, and insights dashboard. Data is persisted locally using Core Data, and spending trends are visualized with Swift Charts to help users understand daily and weekly spending patterns.

Cheap Flight Ticket Finder

Full-Stack Web Application

Flight search platform with real-time API integration and airport autocomplete.

Live Demo GitHub

Click to read more

Cheap Flight Ticket Finder is a full-stack web application that enables users to search for flight options between airports worldwide. Users select an origin airport, destination airport, and departure date to view available flight offers sorted by price.

The application integrates the Amadeus Flight API with OAuth authentication and real-time data parsing, delivering sub-2 second response times. Airport autocomplete searches by city, airport code, country, and IATA code. The backend securely handles API requests and data processing before sending results to the frontend.

Note: This project uses the Amadeus Sandbox API, so flight results are simulated and do not reflect real-time airline availability.
